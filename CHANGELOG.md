# Changelog

## 1.0.0 - 2026-10-23

- Published MT6893 USB Audio Fix as a normal v1.0.0 release.
- Confirmed music playback with both the Moondrop Chu2 DSP and an external USB DAC on the documented Realme X7 Max ColorOS 17 port.
- Retained the same two-byte systemless repair, full library SHA-256 guards and original partition files.
- Updated module metadata and installer wording, retaining the three-step installation display and Action status checks.
- Rebuilt the installable ZIP with the final versioned filename and a new SHA-256 checksum.
- Added a standard-library PC release audit and in-place update instructions.

Compatibility remains limited to the inspected audio/performance library pair. Other phones, ROMs, DAC models, calls, microphones, Bluetooth and long-term stability remain unverified.
